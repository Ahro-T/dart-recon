# dart-recon — DART 재무제표 자동 대사기

OpenDART 재무제표 API(`fnlttSinglAcntAll`)로 상장사 사업보고서를 받아, 공시 숫자들이 서로 맞는지 규칙으로 검사한다.
불일치는 오류 확정이 아니다. 원인(반올림·오타, 재작성, 기준 차이, 우리 규칙의 오탐)을 `triage`로 분류하고 원문 공시와 대조해 판정한다.
표준 라이브러리만 쓴다.

## 규칙 (`dart_recon/rules.py`)
| 규칙 | 검사 |
|---|---|
| `bs_equation` | 자산총계 = 부채총계 + 자본총계 |
| `cf_end_vs_bs_cash` | 현금흐름표 기말현금 = 재무상태표 현금및현금성자산 (+ 현금흐름표 주석의 '매각예정자산집단에 포함된 현금') |
| `cf_bridge` | 기말 − 기초 = 영업 + 투자 + 재무 + 조정항목(환율효과·연결범위 변동 등, 부분집합 중 최적) |
| `cf_net_change_label` | 공시된 '현금 순증감'이 (영업+투자+재무) 또는 (기말−기초) 중 하나와 일치 |
| `cf_prior_end_is_current_begin` | 당기 기초현금 = 전기 기말현금 |
| `restatement` | 올해 보고서의 전기 숫자 = 작년 보고서의 당기 숫자 (자산·부채·자본·현금·매출·순이익·영업CF) |

상태: `ok`, `rounding`(공시 단위 2단위 이내), `mismatch`, `missing`(입력 계정 없음), `reclassified`(restatement 중 중단영업 재분류로 추정되는 매출 감소).
공시 단위(원/천원/백만원)는 숫자의 나눠떨어짐으로 추정한다.

## 실행
```
echo DART_API_KEY=... > .env            # .env, data/는 커밋하지 않는다
python3 -m dart_recon.run --year 2025 --sample 600 --seed 7      # data/raw에 캐시하며 수집
DART_OFFLINE=1 python3 -m dart_recon.run --year 2025 --sample 600 --seed 7   # 캐시만 사용
python3 -m dart_recon.triage --year 2025 --sample 600 --seed 7   # 원인 분류
python3 -m unittest discover -s tests -t .
```
DART 서버는 연속 요청 시 연결을 끊는다. 새로 받을 때는 직렬로 천천히 받는다.
출력: `results/findings_*.jsonl`, `summary_*.json`, `triage_*.json`. `*_before.*`는 이번 규칙 보강 전 결과.

## 결과 요약 (2025 사업보고서, 상장사 4,019개 중 600개 표본, seed 7)
검증 가능했던 회사 323개(공시 없음 150, 수집 실패 127). 모든 숫자는 `results/` 파일에서 나온 것.

| 규칙 | 불일치 건수 전 → 후 | 불일치 회사 수 전 → 후 |
|---|---|---|
| cf_end_vs_bs_cash | 9 → 7 | 7 → 6 |
| cf_net_change_label | 14 → 12 | 10 → 9 |
| cf_bridge | 15 → 15 | 12 → 12 |
| cf_prior_end_is_current_begin | 3 → 3 | 3 → 3 |
| restatement | 120 → 113 (+7 reclassified) | 41 → 34 |
| **전체** | **161 → 150** | **60 → 52** |

원인 분류(`triage_2025_n600_s7.json`, 규칙 보강 후 남은 비정상 152건 = mismatch 150 + rounding 2): 재작성·기타 restatement 99, 원 단위 1만 원 이하 반올림·오타급 25, 미분류 27, 매각예정 현금 가설 1.
보강 전에는 비정상 163건 중 restatement_discontinued 7, held_for_sale_cash 3, column_shift 2가 별도 범주였다(`triage_2025_n600_s7_before.json`).
원문·API로 판정한 사례는 `results/verified_cases.md`.

## 불일치 → 원인 조사 → 규칙 승격 사례
- **롯데지주**: 현금흐름표 기말현금이 재무상태표 현금보다 359,586,889원(전기 1,227,929,244원) 큼. 같은 현금흐름표의 「당기말 매각예정자산집단에 포함된 현금및현금성자산」 줄이 두 금액과 정확히 일치. → `cf_end_vs_bs_cash`가 이 줄을 더해 비교. 지금은 ok. (API 수치로 판정, 원문은 미확인)
- **퀀타매트릭스**: '순증감'이 기말현금과 같아 열 밀림으로 의심했으나, 회사가 순증감 표준코드를 '기말의 현금및현금성자산' 줄에 잘못 붙인 것이고 실제 순증감 줄은 정합. → 이름이 기초/기말인 줄은 순증감으로 읽지 않음(오탐 제거).
- **효성화학**: 전기 매출이 2024 보고서보다 3,859.7억원(13.6%) 적음. 순이익·자산·자본은 불변이고 2025 보고서 주석 15에 중단영업(네오켐·온산탱크터미널·TPA 사업부)이 있음. → 같은 패턴을 `reclassified`로 표시(7개사, 효성화학만 원문 확인, 나머지는 추정). 단 중단영업 영업수익 합과 감소액이 같지 않아 금액 대응은 미확인.
- **SK디스커버리**: 전기 자산 +645.9억, 순이익 +151.9억. 주석에 관계기업 매각계획 변경에 따른 전기오류수정 재작성이 공시되어 있고 조정표 금액이 우리 차이와 일치. 오탐이 아니라 규칙이 잡은 진짜 재작성(공시됨)이므로 `mismatch`로 유지.
- **삼정펄프**: 규칙 4개가 정확히 1,000원 차이를 보고. 2024 보고서와 2025 보고서 비교로 전기 열 기말현금 한 칸이 원인임을 확인(독립 4건이 아닌 1건). 진짜 불일치이나 소액.
- **원인 미확인**: 청담글로벌(기초현금 vs 전기 기말현금 31억), 삼양홀딩스(현금 소액 차이), 메타케어(전기 자산·자본 +11.2억, 순이익 −7.8억).

## 한계
- 표본 600개 중 323개만 검증됨. 수집 실패 127개는 결과에 없다.
- `reclassified`, `held_for_sale_cash` 등은 데이터 패턴에서 나온 가설이며 일부만 원문으로 확인했다.
- `restatement`는 올해와 작년 보고서가 같은 재무제표 구분(연결/별도)일 때만 비교한다.
