# DART 재무제표 정합성

dart-recon MCP 서버의 도구로 회사의 사업보고서를 검사한다.

## 순서
1. 사용자가 묻는 회사와 연도를 파악한다.
2. `dart_check`로 검사를 돌린다. 불일치가 있으면 `dart_explain`으로 원인 후보를 본다.
3. 전기(비교연도) 숫자가 이전 보고서와 다르다는 질문이면 `dart_history`로 계정별 최초값과 최신값을 확인한다.
4. `dart_explain`이 반환한 원인 후보 중 도구 출력(detail, 근거)이 직접 뒷받침하는 후보가 있으면, 그 후보를 원인으로 명시적으로 결론 내린다. 후보가 있는데도 "원인 불명"으로 남기지 않는다. 도구 출력이 어떤 후보도 뒷받침하지 않을 때만 원인 불명이라고 말한다.
5. 결과를 사용자에게 설명한다. 숫자는 도구가 반환한 값만 인용하고, API 기반 검사의 한계(원문 주석 미확인)를 함께 밝힌다.

## 도구
- `dart_company`: 회사 검색
- `dart_check`: 규칙 검사 (회사, 연도)
- `dart_explain`: 불일치 원인 후보
- `dart_history`: 계정별 최초값과 최신값
- `dart_rules`: 규칙 목록과 문서
