# DART 재무제표 정합성

dart-recon MCP 서버의 도구로 회사의 사업보고서를 검사한다.

## 순서
1. 사용자가 묻는 회사와 연도를 파악한다.
2. `dart_check`로 검사를 돌린다. 불일치가 있으면 `dart_explain`으로 원인 후보를 본다.
3. 결과를 사용자에게 설명한다.
4. 금액을 말할 때는 도구가 반환한 값을 그대로(원 단위 숫자 그대로) 옮긴다. "약 1만 원", "수만 원 수준"처럼 스스로 반올림·환산·단위 변환한 표현은 쓰지 않는다. 차이를 직접 계산해 새 숫자를 만들지 말고, 도구가 준 차이값이 있으면 그것만 인용한다. 소액·반올림 차이라는 판단은 숫자를 바꾸지 말고 "도구가 보고한 차이값이 작다"는 서술로 한다.

## 도구
- `dart_company`: 회사 검색
- `dart_check`: 규칙 검사 (회사, 연도)
- `dart_explain`: 불일치 원인 후보
- `dart_history`: 계정별 최초값과 최신값
- `dart_rules`: 규칙 목록과 문서
